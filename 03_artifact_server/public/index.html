Additional Migration Components Provider integration

These proprietary components are not included in this repository. Obtain a compatible Linux archive from its supplier under the applicable license terms.

  1. Obtain the archive required by your provider integration
  2. Keep the archive contents unchanged; the filename must match *.tar.gz. The build preserves the complete directory layout.
  3. Upload one *.tar.gz component archive here. If several are present, remove the extras before building.

Management CA Certificate Required for MTV

TLS certificate for trusted connections to the legacy virtualization API.

  1. Browse to https://<manager-host>/certs/download.zip
  2. Extract the zip and find the CA certificate (usually in certs/lin/)
  3. Upload as management-ca.crt
